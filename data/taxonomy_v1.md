## Правила пограничных случаев (приняты при пересмотре)
- Открыли, построили, отремонтировали объект: тип 4. Оборудование для больниц: тип 1.
- Слова руководителя в центре: тип 8; если в центре отрасль (АПК, логистика): тип 9; если ход строительства объекта: тип 4.
- Практическая польза жителю (кто, где, как получить): тип 1. Информация для избирателей: тип 1; ход и итоги выборов: тип 8.
- Ветеран СВО в центре поста: тип 2; спортивное соревнование ветеранов: тип 6.
- Мероприятие памяти, патриотическая смена, Центр «ВОИН»: тип 3.
- Деловой форум или выставка: тип 9; пленарное заседание с чиновниками: тип 8.
- Призыв голосовать за благоустройство: тип 10; итоги голосования: тип 4.

## Файлы
- `labels_2026-04_2026-09.csv`: `id`, `type`, `type_name`, `type_pass1` (тип первого прохода), `confidence_pass1` (high или low), `alt_type` (запасной тип для пограничных), `reviewed` (1, если пост пересматривался по полному тексту).
- `validation_blind.csv`: 60 постов без моих меток; заполните колонку `your_type` числом 1–10.
